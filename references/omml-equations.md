# OMML 公式（python-docx 嵌入可编辑公式）

专利说明书里的公式用 **Office Math Markup Language（OMML）** 嵌入 `.docx`，Word/WPS 可编辑。
**禁止**用纯文本伪公式（`D_raw = ...`）冒充定稿公式；实施例符号表与式(n)必须同形。

复用实现：`scripts/omml_utils.py`（`msub` / `msup` / `mfrac` / `mdelim` / `mnary` / `momath` / `fill_mixed`）。

## 一、硬规则（2026-08 真实踩坑：角标全空）

用户报「公式上下角标全是空的 / 空方框 ❑」时，**几乎一定是 OMML 结构错**，不是字体问题。

### 1. `m:sub` / `m:sup` 内禁止再包 `m:e`

| | 结构 |
|---|---|
| ❌ 错误 | `m:sSub` → `m:e`(基) + `m:sub` → **`m:e`** → `m:r` |
| ✅ 正确 | `m:sSub` → `m:e`(基) + `m:sub` → **直接** `m:r` / 子结构 |

错误结构在 XML 里 `itertext()` 仍有字，但 LibreOffice / 部分 WPS 渲染会把角标画成 **空方框 ❑**。
`msub`/`msup` 必须以「角标子节点直接挂在 `m:sub`/`m:sup` 下」实现（见 `omml_utils.py`）。

### 2. nary 空限不要留空节点

`∑`/`∫` 若无上限或无下限：**省略**对应的 `m:sub`/`m:sup`，不要写空的 `<m:sup><m:e/></m:sup>`（也会出 ❑）。

### 3. 绝对值 / 集合基数符号

优先用 Unicode **`∣`（U+2223）**，少用 ASCII `|`。后者在 LO 导出 PDF 时易被渲成 `¿` / `∨¿`。

### 4. 复杂求和优先平铺

若 `mnary` 在目标环境渲染不稳，改用：

```text
(1/|Ω|) · ∑_{x∈Ω} |I_t(x) − I_{t−1}(x)|
```

对应 OMML：`mfrac` + `msub(mr("∑"), [...])` + 后续绝对值项平铺，比带空限的 `nary` 更稳。

### 5. 计数 ≠ 可见

`document.xml` 里有 N 个 `m:oMath`、文本审计「无 ISSUES」**不能**证明角标可见。
**必须** `soffice`→PDF→`pdftotext` / 逐页 PNG，检查：

- `❑` 计数 = 0  
- 公式页肉眼可见下标（如 `D_raw`、`τ_stop`、`Acc_v`）

## 二、与正文一致性

- 发明内容先写**符号表**（`I_t`、`D_raw`、`η`…），再写式(1)(2)…；符号表与 OMML **同形**。
- **式 OMML 与正文同构**：独立公式的 OMML 展开须与说明书文字中的等式同一结构（同一损失/目标/约束），禁止「正文写 A、OMML 画成 B」。
- 有益效果、实施例引用「式(n)」时编号与插入顺序一致。
- 权利要求保持宽泛、一般不嵌 OMML；公式细节进发明内容 + 实施例。
- **禁止悬空式号 / 装饰公式**：写「式(n)」或「式(n)等价」后**必须有等式本体**（`左边 = 右边`）；仅有「其中…」说明而无等式 = 未公开。audit 应拒悬空式号。
- **一名多义禁止**：同一符号不能既表示特征向量又表示 0-1 决策变量、既表示集合又表示标量等；若集合与标量易混，用上标区分（例：正样本集合用 `P^+`，避免与未加标的 `P` 冲突）。
- **改公式必同步**：符号表、发明内容、实施例、OMML 装配、行内模式、门禁关键字——六处一致，禁止旧变量回潮。

## 二点五、行内 OMML（正文符号）

- 源码行文写 ASCII 伪下标（如 `w_e`、`theta_hi`、`x_{i,j}`），**装配时**经 `parse_inline_math`（或等价）转为正式 `m:sSub` / `m:sSup`；不要把 Unicode 下标字符或手嵌 Word 公式当内容源定稿。
- 新符号：先在行内解析模式中登记更长、更具体的正则，再写进正文；装配后确认纯文本 `w:t` 无残留下划线伪写法。
- 权威预览以 Word/WPS 为准；LibreOffice→PDF 常抽不出行内希腊字母，**不能**仅据此判失败；仍查 ❑/□/¿/�。

## 三、装配后公式自检脚本要点

```python
# 1) XML：任一 m:sub/m:sup 下若仍有 m:e → FAIL   # nested m:e 禁令
# 2) 任一 m:sub/m:sup 的 itertext 为空 → FAIL
# 3) PDF 文本中 ❑ 计数 > 0 → FAIL
# 4) 式号 (1)…(n) 均在正文出现，且式号后有等式本体（禁悬空）
# 5) 独立 OMML 与正文等式关键字同构；易混符号已用上标等区分
# 6) 行内：源 ASCII 下标已转 OMML；w:t 无残留伪下标定稿
```

## 四、术语（与公式旁白）

通用缩写：**首次**写「中文全称（英文）」，后文可用英文。例：感兴趣区域（ROI）、交并比（IoU）、神经处理单元（NPU）。
公式旁说明文字与权利要求/发明内容/实施例三处术语锁定，勿混用未定义缩写。
自动包 `$` / 行内数学时保护专有词与步骤号（如模型名、S1…），勿误拆中文括号内说明。
